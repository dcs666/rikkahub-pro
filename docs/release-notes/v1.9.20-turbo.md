# v1.9.20-turbo 版本说明

## ✨ 新功能

- **生成打断警示**：生成被新消息/停止打断时，半截回复末尾自动追加可见警示「⚠️ 生成被新消息打断，回复不完整（已取消）」，不再看起来像"卡死"；同时写入 App 内存日志（Logging）便于远程诊断
  - 幂等：同一消息不会重复追加
  - 警示条带 `uiNotice` 元数据，构建请求时自动过滤，不会作为历史回传污染模型上下文

## 🔒 安全修复

- **Webhook 端点强制签名认证**：未配置 GitHub Token 时 `/api/tasks/webhook` 直接 403 关闭（此前完全无校验，设备内任意 App 可伪造 CI 结果并注入用户对话，构成提示词注入向量）；配置 Token 后 HMAC-SHA256 校验无条件强制

## 🐛 修复

- **opencodeStrict 消息内多 item 重复 id**（C1）：同一 assistant 消息的文本缓冲被图片/推理/工具组打断后多次 flush 时，各段复用 `msg_<id>` 顶层 id；多图复用 `img_<id>`；多段真实 reasoning 复用 `rsn_<id>`。上游按 id 反序列化输入数组，重复 id 有覆盖/被拒风险。现改为消息内自增序号：`msg_<id>_N` / `rsn_<id>_N` / `img_<id>_N`（fc/fco 的 id 配对约束不受影响）
- **截断提示不再污染历史**：服务端截断警示（max_tokens/length）补 `uiNotice` 标记，四个请求构建器（Response/ChatCompletions/Claude/Google）统一过滤，警示文本不再随历史回传
